# Game-Flix

**A cosmic leaderboard game with AI storytelling and Web3 rewards**


## Overview
Game-Flix is a gamified entertainment universe that merges data-driven gameplay, Web3 rewards, and AI-driven storytelling for an interactive leaderboard journey set in space.



## Features
- Real-time astronaut leaderboard
- API feeds from Launch Library and gaming APIs
- AI host narrator with cinematic storytelling
- MetaMask login and NFT-based Memory Totem system
- Transmedia narrative bridging games and Netflix films



## Technologies Used
- Python 3.10+
- FastAPI
- Phaser.js
- D3.js
- Web3.js / MetaMask
- PostgreSQL + Redis



## Getting Started
1. Clone the repository
2. Install Python dependencies: `pip install -r requirements.txt`
3. Run `docker-compose up`
4. Access the game at `localhost:3000` and API at `localhost:8000/docs`
